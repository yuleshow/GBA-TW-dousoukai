Fusion Pixel Font 8px monospaced, zh_hant, release 2026.09.01.

Release archive: https://github.com/TakWolf/fusion-pixel-font/releases/download/2026.09.01/fusion-pixel-font-8px-monospaced-bdf-v2026.09.01.zip

Archive SHA-256: `c2e1fca87eafb0f5dbae64378a8a73f85499479ce67616e6eaa618f85c55f626`

BDF SHA-256: `be85f01e270198b9e8d5863f1f552debd6689be82a3a3ca3620c16859ccd9ce4`

The BDF and its additional licenses in LICENSES/ were extracted unchanged.
The shared OFL.txt and galmuri license match both release archives exactly.
Name sprites use this native font with ascent 7, descent 1 and BBX offsets
in an 8x8 cell, without scaling down the 12px font. The default dialogue
font remains 12px. Both sizes reject missing, blank and oversize glyphs.
